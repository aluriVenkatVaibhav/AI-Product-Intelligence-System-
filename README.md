# AI Product Intelligence System

An AI-powered product intelligence system using CLIP and FAISS for semantic product search, duplicate detection, and smart product recommendations.

## Overview

The project explores multimodal product understanding using vision-language embeddings and vector similarity search.

### Core Features

- Natural-language reverse product search
- Visual duplicate product detection
- Smart complementary product recommendations

## Technology Stack

- Python
- PyTorch
- CLIP
- Hugging Face Transformers
- FAISS
- Pandas
- NumPy
- Pillow
- Matplotlib
